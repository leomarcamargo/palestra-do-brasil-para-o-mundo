# Modelo de currículo em inglês

Um modelo de uma página, simples, para quem está na graduação e quer se candidatar a vagas internacionais.

[Voltar ao início](../README.md)

## Arquivos

| Arquivo | Para que serve |
|---|---|
| [resume-template.docx](resume-template.docx) | Versão editável no Word ou no Google Docs. **Use esta para criar o seu.** |
| [resume-template.pdf](resume-template.pdf) | Versão para visualizar como fica pronto. |
| [resume-template.md](resume-template.md) | O mesmo conteúdo em texto simples. |

## Como usar

1. Baixe o `.docx` e troque tudo o que está entre colchetes `[ ]` pelas suas informações.
2. Apague as seções que não fazem sentido para você agora. Se ainda não tem experiência, apague "Experience" e capriche em "Projects".
3. Salve como **PDF** com o nome `Nome-Sobrenome-Resume.pdf`.
4. Abra o PDF no navegador e tente selecionar o texto. Se conseguir selecionar, os sistemas de triagem (ATS) também conseguem ler.

## As regras do modelo

| No Brasil é comum | No currículo internacional |
|---|---|
| Foto, idade, estado civil, CPF | **Não inclua** |
| Endereço completo | Só cidade, estado e país |
| 2 ou 3 páginas | **1 página** |
| Colunas, ícones, barras de nível | **1 coluna, texto simples** |
| Lista de responsabilidades | **Resultados** |
| Português | **Inglês** |

Enquanto você estuda, **Education** e **Projects** vêm antes de **Experience**.

## A fórmula de cada linha

```
verbo + o que fez + tecnologia + resultado real
```

| Parte | Exemplo |
|---|---|
| Verbo | **Built** |
| O que fez | **a library system** |
| Tecnologia | **with Java and MySQL** |
| Resultado real | **used by students every day** |

Linha completa: *Built a library system with Java and MySQL, used by students every day.*

O resultado não precisa ser um número. Uso real também conta. **Nunca invente.**

### Verbos que funcionam bem

Built, Created, Developed, Designed, Improved, Fixed, Tested, Automated, Organized, Wrote, Helped, Led.

Evite começar com "Responsible for" ou "Worked on". Eles descrevem a tarefa, não o que você fez.

## IA no currículo: pode e não pode

| Peça para a IA | Não deixe a IA |
|---|---|
| Corrigir o seu inglês | Inventar números |
| Deixar a frase mais clara e curta | Colocar tecnologia que você não usou |
| Sugerir um verbo melhor | Exagerar o seu papel no projeto |
| Conferir se a linha segue a fórmula | Escrever algo que você não sabe explicar |

Tudo o que está no currículo pode virar pergunta na entrevista.

## Como o ATS lê o seu currículo

| Lê bem | Lê mal |
|---|---|
| PDF gerado de texto | Currículo em imagem ou escaneado |
| Uma coluna, texto simples | Tabelas, colunas e caixas de texto |
| Títulos padrão: Education, Experience, Skills | Ícones e barras de "nível" |
| As palavras exatas da vaga | Siglas soltas: "JS" no lugar de JavaScript |

## Regra de ouro

Nome, cargos, empresas e datas devem ser **iguais** no currículo e no LinkedIn.
